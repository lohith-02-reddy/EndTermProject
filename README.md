# Rock Paper Scissors Game 🎮

A simple **Rock Paper Scissors** game built with **HTML, CSS, and JavaScript**. Play against the computer and see who wins!  

---

## Demo

- Click **Rock**, **Paper**, or **Scissors** to make your move.  
- The computer will randomly choose its move.  
- The result and scores are displayed instantly.  
- Click **Reset Game** to start over.  

---

## Features

- Track your score against the computer.
- Reset functionality to start a new game.
- Stylish buttons with hover effects.
- Responsive and visually appealing gradient background.

---

## How to Run

1. Clone or download this repository.  
2. Make sure you have the following files in the same folder:
   - `index.html` → The main HTML page.
   - `style.css` → The CSS file for styling.
   - `script.js` → The JavaScript logic.  
3. Open `index.html` in your web browser.  
4. Start playing!
